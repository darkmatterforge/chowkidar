# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-06-01

### Added
- Initial public release of Chowkidar
- Multi-architecture Docker images (`linux/amd64` and `linux/arm64`)
- Embedded web templates for simplified production deployments
- Docker container monitoring with configurable actions:
  - Start
  - Stop
  - Restart
  - Notify
- Webhook notification support
- Gotify notification support
- Health check API endpoint
- Configuration loading from files and environment variables with defined priority handling
- Unraid Community Applications template
